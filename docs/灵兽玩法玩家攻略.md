# 《诸天灵契》灵兽攻略

> 万灵古印映照六界灵影。你可以寻踪、鉴灵、培养血脉与技能，再以一主两辅灵阵征战副本、轮海深渊、队伍战斗和世界 Boss。

## 一分钟入门

1. 完成首次副本，发送“灵兽”，在赤焰灵狐、玄甲龟、青木鹿、寒翎雀中任选一只初契伙伴。
2. 发送“灵兽阵容”，确认它已进入当前角色的主契位。
3. 发送“灵兽培养 灵兽编号”，用御兽灵息喂养；到达境界上限后发送“灵兽突破 灵兽编号”。
4. 每日首次完整通关副本可获得诸天兽踪，发送“灵兽寻踪”并选择线索，再发送“灵兽鉴定”。
5. 每天照料一次、手动完成前三场 PVE，让灵兽稳定获得羁绊。

初契四选一：

- 赤焰灵狐：攻伐追击，适合快速推图；
- 玄甲龟：守御护主，适合越级抗压；
- 青木鹿：生息回复，适合深渊续航；
- 寒翎雀：控场抢速，适合需要先手的阵容。

## 寻踪、鉴灵与保底

“灵兽寻踪”会发现一处六界兽踪，随后可从稳定、稀有、未知三类线索中选择。稳定线索适合日常积累，稀有线索更容易靠近高品质，未知线索波动较大。

鉴灵消耗兽魂石，拥有两层硬保底：连续10次内必得地品或更高，连续60次内必得天品。保底按账号保存，切换线索或角色不会清空。

抽到重复灵种时不会强塞进收藏。你可以选择：

- 保留新个体：适合不同资质、性情或多套灵阵；
- 化为灵种精魄：用于该灵种共享的血脉觉醒；
- 转为通用材料：适合集中培养主契。

## 六条养成线

### 等级与境界

御兽灵息用于升级，灵兽等级不能超过角色等级，也不能越过当前境界上限。境界依次为幼灵、启智、凝丹、化形、返祖、真灵、太古，突破消耗基础兽材与灵石。

### 四维资质

灵力、体魄、神魂、迅捷共同决定战力与定位强度。“灵兽洗髓”只生成预览，不会立刻覆盖；满意后确认，不满意可取消。连续未提升会触发保护，避免长期倒退。

### 血脉

同名灵种共享六个血脉节点。第3节点解锁血脉技能，第6节点完成返祖并提高有效品质。血脉和灵种精魄在归真后永久保留。

### 传承技能

技能书使用后永久进入灵契书库。启智开放第一个技能槽，化形开放第二个；技能可反复装配和无损卸下，覆盖不会销毁。

### 性情与羁绊

抚摸、静观、讲道、竞速分别偏向沉稳、灵慧、勇猛、机敏。连续3天选择同类互动可定向改变性情。羁绊2、4、6、8级解锁传记，5级可改名，7级开放入场描述，10级解锁纪念协同。

## 一主两辅灵阵

- 主契：主人行动后自动协战，释放天赋、血脉和传承技能；
- 护契：在低血、护盾或团队受压时响应一次；
- 辅契：负责开场控场、追击或破局，每场有限触发。

灵兽园 Lv.4 解锁护契，Lv.7 解锁辅契，Lv.10 解锁三套灵阵预设和一键照料。相同世界2只、3只可激活世界共鸣；三只不同元素可激活五行灵阵。两种路线强度接近，可以放心混搭。

推荐阵容：

- 日常速攻：攻伐主契＋控场护契＋破阵辅契；
- 深渊续航：生息主契＋守御护契＋控场辅契；
- 首领破局：破阵主契＋守御护契＋生息辅契。

战斗开启时会冻结灵阵、资质、血脉与技能。中途换阵只影响下一场；深渊层内沿用开层快照，主契灵体在怪物之间恢复30%。

## 每日与每周路线

- 每日：完整通关一次副本拿兽踪；照料一次；手动完成前三场 PVE 拿羁绊。
- 洞府：收取灵兽园产出的御兽灵息；未上阵灵兽可派遣4、8或12小时。
- 每周：完成灵兽周记；挑战万灵秘境的血脉、技能或羁绊路线；参与护山灵兽供养和世界 Boss 万灵弱点。
- 扫荡：只给基础兽材和少量灵息，不给羁绊与专属故事，手动挑战仍有价值。

基础兽材是唯一可交易的灵兽养成材料，可在坊市上架或收购；兽踪、兽魂石、洗髓露、血脉精华、灵种精魄和灵契残页均为绑定资源。

## 归真与换养

单只归真会先展示返还清单，再要求确认。等级和境界培养材料100%返还，血脉、羁绊、传记、图鉴最高资质及技能书库永久保留。每周前三次免费，之后每次收取2000灵石；重制上线首周按迁移标记免费调整。

“灵兽批量归真”只处理灵品、玄品普通灵兽，并自动排除地品、天品、已命名、已锁定、羁绊5级以上、上阵及派遣中的灵兽。
