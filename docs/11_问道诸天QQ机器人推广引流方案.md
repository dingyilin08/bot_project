# 《问道诸天》QQ 机器人游戏推广引流方案

> 适用版本：v1.27  
> 制定日期：2026-08-10  
> 推广目标：用内容平台获取精准玩家，以 QQ 好友/群聊完成注册、激活、组队与裂变。  
> 结论先行：它不应被包装成普通“文字挂机游戏”，而应定位为 **“不用下载，拉进 QQ 群就能和朋友一起玩的策略修仙 RPG”**。

---

## 0. 一页作战板

| 项目 | 建议 |
| --- | --- |
| 产品定位 | 群聊原生、轻量进入、多人协作的策略修仙 RPG |
| 核心卖点 | 不用下载；群聊直接玩；手动回合战斗；组队、宗门、世界 Boss；长期养成 |
| 核心人群 | 16～30 岁修仙网文/文字游戏用户、QQ 群活跃用户、宿舍/同学/游戏群群主、低配置与碎片时间玩家 |
| 第一传播句 | **“把机器人拉进 QQ 群，全群就多了一款修仙 RPG。”** |

| 首发活动 | “百人开荒测试”：限 100～300 名真实玩家，连续 14 天，以共创、攻略和组队夜建立第一批核心用户 |
| 渠道优先级 | S：QQ 生态、B站；A：抖音、小红书；B：贴吧/垂直社群、知乎；观察：TapTap |

| 30 天验证目标 | 先验证 200～500 名注册玩家、30～80 个有效游戏群；未验证留存前不建议大额投流 |

### 两套宣传口径

**A. 已取得完整 IP 授权时**

> 萧炎、韩立、石昊等六大主角跨界集结，在 QQ 群里组队问道。无需下载，发送指令即可修炼、炼丹、养灵兽、打世界 Boss。

**B. 未取得完整 IP 授权时（建议采用）**

> 六大道途、六种战斗流派，在 QQ 群里共同修仙。无需下载，发送指令即可修炼、炼丹、养灵兽、组队挑战世界 Boss。

未获得权利方书面许可前，不应在账号名称、标题、封面、投流素材、达人脚本中使用知名小说名、角色名、影视/动漫形象或“正版联动”等表达。

## 1. 项目通览后的推广判断

### 1.1 已具备的增长基础

| 已实装能力 | 推广价值 | 可直接使用的传播表达 |
| --- | --- | --- |
| QQ 好友与群聊欢迎页、注册按钮 | 新玩家无需学习复杂接入流程 | “加好友或拉进群，点注册就能玩” |
| 单人手动回合战斗 | 有真实操作和策略画面，适合录屏 | “五行反应、道心、Boss 天机，不是纯挂机算数值” |
| 同群队伍与多人回合战斗 | 最鲜明的 QQ 原生差异点 | “群友每人提交一回合行动” |
| 宗门、师徒、世界 Boss、赛季 | 能把一次试玩转成长线社群 | “一个 QQ 群就是一个修仙宗门” |
| 药园、炼丹、洞府、灵兽、坊市 | 内容量足，适合持续做攻略 | “战斗外也有经营和收集循环” |
| 七项新手札记、今日修行、日常任务 | 已有激活和回访抓手 | “15 分钟完成每日闭环” |
| 八位邀请码与双阶段奖励 | 已有玩家裂变机制 | 注册双方各得 500 仙玉 + 1600 灵石；新玩家完成七项札记后双方再各得 1000 仙玉 |
| 680×680 玩法宣传图与角色图 | 有首批图文素材基础 | 可改造成小红书/B站动态九宫格和视频插图 |
| v1.27 更新日志与完整攻略 | 适合做开发者日志和搜索内容 | “持续更新中的群聊修仙项目” |

### 1.2 当前不宜直接放量的四个问题

1. **IP 权利风险是硬闸门。** 项目直接使用知名文学作品的角色、世界、能力名称，并配有高识别度角色视觉。公开推广与商业投流会显著扩大风险。先取得授权，或完成原创角色、世界、技能和视觉的系统性替换。
2. **品牌名不统一。** 运行代码与欢迎页主要使用《问道诸天》，部分玩家攻略使用《诸天问道》。对外只保留一个名称，账号昵称、头像、落地页、群名、攻略标题和素材角标全部统一。
3. **缺少渠道归因。** 当前邀请码是玩家维度，不是渠道维度；代码中未发现注册来源、内容批次、达人或落地页参数的完整埋点。没有归因就无法判断哪个平台带来的是“注册”还是“七项札记完成者”。
4. **素材有世界观图，但缺真实产品证据。** 现有方图适合做氛围图，最关键的“QQ 群里真的能玩”仍需要真实手机录屏、聊天界面、按键操作、多人提交行动和结算画面。

### 1.3 推荐的品牌表达

- 品牌名：统一为 **《问道诸天》**（若名称权利检索不通过，再换原创名）。
- 品类名：**QQ 群聊策略修仙 RPG**。
- 主口号：**把机器人拉进群，全群一起修仙。**
- 副口号：**不用下载，发消息就能玩。**
- 产品关键词：群聊游戏、回合策略、多人协作、修仙养成、碎片时间、无需下载。
- 避免主打：“免费送仙玉”“挂机暴富”“无限抽卡”“正版联动”等可能误导或放大合规风险的表述。

## 2. 放量前的四道闸门

### G0｜权利与运营合规

- 梳理角色名、作品名、世界名、能力名、图片、字体、音乐和音效的权利来源，保存授权链与创作源文件。
- 未授权素材全部原创化，不能只改一个字或换颜色；角色设定、世界结构、视觉轮廓和宣传文本都应形成独立表达。
- 在开放注册、收费、广告合作或达人投放前，让熟悉网络游戏与互联网内容业务的律师/合规顾问确认主体资质、审批/备案、未成年人保护、隐私政策、用户协议、虚拟道具与抽取机制披露要求。
- 如以后充值，祈愿概率、保底、虚拟货币、活动时限、退款与未成年人规则需要单独审查，不能沿用“内测免费”阶段口径。

### G1｜统一品牌与入口

- 全项目统一《问道诸天》或新的原创名称。
- 准备一个可复制的唯一入口：短链接落地页，页面只保留“添加机器人”“加入官方群”“群主添加到群”三个按钮及 20 秒演示。
- 每个平台使用独立短链/二维码；若平台限制外链或外部联系方式，改用平台原生私信自动回复或主页合规入口，不在正文硬塞 QQ 号。
- 官群不要只显示群号，还要说明用途：新手答疑、开荒组队、更新公告、Bug 反馈。

### G2｜最短激活链路

新用户首次体验最多只做四步：

1. 添加机器人或进入试玩群。
2. 点击“注册游戏”并输入昵称。
3. 选一个角色/流派。
4. 进入一场 1～3 回合的教学战并看到奖励。

当前七项札记适合承接后续深度激活，但推广流量的第一次正反馈不能等到播种、炼丹和商城全部体验之后。建议给欢迎页增加“60 秒试玩”或把首场教学战前置；若暂不开发，运营人员在试玩群置顶三条消息：注册、选角、首战。

### G3｜数据归因与看板

至少增加下列字段或事件：

- `acquisition_source`：qq_group / bilibili / douyin / xiaohongshu / tieba / taptap / creator 等。
- `campaign_code`、`creative_code`、`referrer_uid`、`first_group_openid`。
- 事件：入口点击、添加机器人、入群、注册、选角、首次战斗、首次胜利、札记 3/7 和 7/7、首次组队、首次邀请、D1/D3/D7/D14 活跃。
- 群级指标：新增玩家数、3 人激活率、首场多人战时间、7 日活跃人数、消息量与退群/投诉。

每个达人、平台和素材必须使用唯一活动码。玩家邀请码继续负责裂变奖励，渠道码负责营销归因，二者不要混为一套。

## 3. 目标用户与对应钩子

| 人群 | 痛点/动机 | 最有效钩子 | 适合平台 |
| --- | --- | --- | --- |
| 修仙网文与文字游戏用户 | 喜欢脑补、养成、长期目标，不追求高画质 | 六种流派、境界、本源、炼丹、灵兽 | B站、小红书、贴吧、知乎 |
| 宿舍/同学/游戏群 | 想找群内共同话题，厌倦下载新 App | “拉机器人进群，今晚直接开荒” | QQ 群、抖音、B站 |
| QQ 群主/管理员 | 需要活跃群聊和低门槛活动 | 群内组队、宗门、周 Boss、群榜 | QQ 生态、群主社群 |
| 策略与数值党 | 喜欢研究配装、回合、克制与排行榜 | 五行反应、道心、Boss 天机、阵法 | B站、贴吧、知乎 |
| 收集与经营党 | 喜欢养成、图鉴和稳定日常 | 灵兽、药园、炼丹、洞府、坊市 | 小红书、B站动态 |
| 独立游戏/开发关注者 | 愿意参与测试和共创 | “一个人如何把 QQ 群做成 RPG” | B站、知乎、TapTap 社区 |

首发不要试图覆盖所有人。建议先抓两个种子群：**群主/管理员**与**修仙文字游戏核心用户**。前者带来整群关系链，后者能产出攻略与有效反馈。

## 4. 转化漏斗：内容不是终点，组队才是

```text
内容曝光
  → 看见“QQ群里能直接玩”的真实证据
  → 添加机器人 / 加入试玩群 / 群主添加到群
  → 注册并选角
  → 24小时内完成首战
  → 72小时内完成七项札记
  → 邀请1名好友或在本群完成首次组队
  → 成为周活跃玩家 / 周活跃游戏群
```

### 建议测试阈值

这些是首轮优化目标，不是行业承诺；两周后按真实基线调整。

| 环节 | 首轮目标 |
| --- | ---: |
| 添加机器人/进试玩群 → 注册 | ≥ 50% |
| 注册 → 选角 | ≥ 80% |
| 选角 → 24 小时首战 | ≥ 45% |
| 注册 → 72 小时札记 7/7 | ≥ 25% |
| D1 留存 | ≥ 35% |
| D7 留存 | ≥ 15% |
| 激活玩家 → 有效邀请注册 | ≥ 20% |
| 新游戏群 → 7 日内完成多人玩法 | ≥ 30% |

一旦“注册→首战”或 D1 明显低于阈值，先修新手体验，不要加大投流。

## 5. 分平台引流打法

### 5.1 QQ 生态｜S 级，承担转化与留存

**目标：** 找到群主，让机器人进入真实关系链；把官方群做成试玩与跨群组队中心。

**具体动作：**

1. 建立 3 类群：官方公告群、开荒试玩群、核心共创群。公告群低频；试玩群每晚组织一场活动；共创群只收高活跃玩家、攻略作者和群主。
2. 招募“开荒群主”：首批 20～50 位，每位带一个 10 人以上真实群。给身份、专属称号或共创署名，不用现金购买刷量。
3. 设计固定周节奏：周一宗门招新、周三阵容讨论、周五组队夜、周末世界 Boss 榜单。
4. 在每个新群发一张“群主三步开服卡”：添加机器人 → 群员注册 → 两人队伍开战。
5. 玩家分享邀请码时提供一键复制文案，但奖励只绑定真实注册与札记完成，不奖励无效转发、刷群或机器账号。

**群招募文案：**

> 群里最近加了一个能直接玩的修仙 RPG，不用下载 App。发送“注册游戏 昵称”就能选流派、打副本；两个人可以组队打回合战，群里还有宗门和世界 Boss。想试的回复“开荒”，今晚一起组队。

**关键指标：** 新增机器人群数、每群注册人数、3 人激活率、首场组队耗时、7 日活跃群率。

### 5.2 哔哩哔哩｜S 级，承担信任与深度种草

**内容结构：** 真实演示 60%，攻略/整活 25%，开发日志 15%。

**建议栏目：**

- 《我把一个修仙 RPG 塞进了 QQ 群》：2～4 分钟产品演示。
- 《群友每人操作一回合，能不能越级打 Boss？》：多人挑战实录。
- 《没有客户端的游戏，怎么做回合战斗？》：开发日志。
- 《零氪开荒第 1 天：15 分钟资源循环》：连续攻略。
- 《100 人共创测试周报》：公开数据、Bug 和改动。

**标题样例：**

1. `我把修仙RPG做进了QQ群：不用下载，全群直接开荒`
2. `4个群友每人操作一回合，真能打赢世界Boss吗？`
3. `一个QQ机器人，为什么要做60座副本和完整炼丹系统？`

封面必须同时出现 **QQ 聊天实机界面 + 一句结果型大字**，不要只放仙侠人物立绘。视频前 8 秒完成“无需下载—群聊能玩—多人提交动作”的演示。B站将原创性作为投稿判断重点，实机录制、本人解说与开发过程比纯素材混剪更稳妥。

**发布节奏：** 每周 1 条主视频 + 2～3 条动态/短切片。评论区置顶当前合规入口，不在所有回复中重复刷群号。

### 5.3 抖音｜A 级，承担“第一眼惊奇”

抖音不讲完整系统，先证明一件事：**QQ 群里真的出现了一款可操作 RPG。**

**15～30 秒脚本：**

- 0～2 秒：`如果一个QQ机器人，真的能在群里开副本？`
- 2～7 秒：手机录屏，群员完成注册和选流派。
- 7～15 秒：两名玩家分别点“技能/防御”，机器人结算 Boss 回合。
- 15～22 秒：掉落、排行榜或世界 Boss 血量变化。
- 22～30 秒：`不用下载，拉进群就能玩｜首批开荒测试中`。

**连续选题：** “群主把机器人拉进死群后的第 7 天”“全群只准练一种流派”“低战力辅助也能拿世界 Boss 贡献”“群友炼丹失败名场面”。

**原则：** 每条只讲一个反差；用真实群聊、真实结算和真实玩家反应。不要用未实现的动画战斗冒充实机，也不要用虚假稀缺、虚假人数或夸大收益诱导。

### 5.4 小红书｜A 级，承担搜索与图文解释

小红书适合“可收藏的体验攻略”，不适合硬贴群号海报。

**图文模板（6～8 页）：**

1. 封面：`不用下载的QQ群修仙游戏，我和群友玩了7天`
2. 怎么开始：加机器人/入试玩群 → 注册 → 选流派。
3. 群聊里如何打回合战。
4. 药园、炼丹、灵兽、洞府的日常循环。
5. 两人组队和世界 Boss。
6. 适合谁、不适合谁。
7. 当前测试期的 Bug/限制，保持真实。
8. 合规入口：主页、私信关键词或平台允许的链接方式。

**标题样例：**

- `群聊也能玩RPG？我把修仙游戏拉进了QQ群`
- `不占内存的文字修仙：15分钟开荒路线`
- `宿舍群新玩法｜两个人就能开的回合制副本`

现有 680×680 玩法图可作内页，但封面优先加入真实聊天界面、品牌名和“QQ 群可玩”角标；发布前校对图中文字与实际玩法。

### 5.5 贴吧、垂直论坛与兴趣社群｜B 级，承担种子用户

优先选择文字游戏、修仙游戏、独立游戏、游戏开发和 QQ 机器人相关社区。先阅读版规并征得版主/群主许可。

**帖子结构：**

- 开头展示真实玩法，不伪装路人推荐。
- 明确身份：“我是开发者，招募首批开荒测试者”。
- 写清已有功能、已知问题、更新频率和需要测试的内容。
- 给出 3 个明确任务：完成首战、参加一次组队、提交一条反馈。
- 每周回帖更新修复结果，让帖子变成开发日志而非一次性广告。

**标题样例：** `独立开发｜把多人回合制修仙做进QQ机器人，招100名开荒玩家`

严禁批量复制同一广告、顶帖刷量、伪装玩家口碑或私信骚扰。

### 5.6 知乎｜B 级，承担开发者品牌与长尾搜索

可回答：

- “文字游戏还有哪些创新交互？”
- “一个人开发多人回合制游戏要解决哪些问题？”
- “如何用 QQ 机器人做群聊游戏？”

正文至少 80% 提供可复用的开发经验，项目只作为案例。文章末尾再放测试招募。它的转化速度慢，但能吸引开发者、攻略作者和高质量共创玩家。

### 5.7 TapTap｜观察渠道，不作为首轮主转化

TapTap 对游戏社区、预约和开发者官方帖很有价值，但当前项目是 QQ 机器人，没有 Android APK。官方文档显示，预约期不强制上传 APK，但创建与正式测试/上线流程仍围绕移动游戏资料和安装包展开。因此：

- 先向平台提交工单，确认“QQ 机器人游戏”能否建立详情页、如何标注游玩方式以及所需资质。
- 获得明确答复前，不把 TapTap 预约量写进首月 KPI，也不把机器人伪装成 APK 游戏。
- 若获准入库，可用“开发中/测试招募”页面沉淀关注，利用官方帖做版本日志和测试公告。

## 6. 首发 campaign：百人开荒测试

### 6.1 活动设计

- 名称：**百人开荒｜把你的 QQ 群变成修仙宗门**。
- 人数：第一期 100～300 人，持续 14 天。
- 参与入口：官方群试玩，或由入选群主把机器人添加到自己的群。
- 核心任务：注册选角、首战、札记 7/7、首次组队、一次世界 Boss、邀请一位真实好友。
- 每晚 20:30 固定活动：新手带队、组队挑战、阵容问答或开发者在线答疑。
- 展示奖励：开荒纪念称号、首批群主身份、攻略作者署名、版本鸣谢。若当前未实装，应明确写“活动结束后人工审核发放/待版本上线”，不得宣传成已经可领取。

### 6.2 现有奖励如何用

项目已经支持：

- 邀请双方注册礼：每人 500 仙玉 + 1600 灵石。
- 被邀请人完成七项札记后：双方再各得 1000 仙玉。
- 七项札记自身还有单项奖励与全完成 1600 仙玉奖励。

宣传中应把条件写完整，不只写“送 2600 仙玉”。奖励目的应是带朋友完成真实体验，而不是换取点赞、关注、转发或好评。

### 6.3 每日社群节奏

| 时间 | 内容 | 目的 |
| --- | --- | --- |
| 09:00 | 今日修行提醒，仅 1 条 | 回访 |
| 12:30 | 一条短攻略/阵容卡 | 降低理解成本 |
| 20:30 | 组队夜或世界 Boss | 制造同步在线 |
| 22:00 | 战报、群榜或名场面 | 社交证明与次日内容素材 |

不要让机器人在群里无触发刷屏。运营消息应由玩家订阅或群管理员控制频率。

## 7. 30 天执行排期

### 第 0 周｜上线准备（3～7 天）

- 完成 IP/资质/隐私与未成年人合规确认。
- 统一品牌名、头像、简介、官方群命名和入口。
- 建立平台/达人/素材渠道码与基础数据看板。
- 录制 10 段真实实机：注册、选角、单人回合、组队、Boss、灵兽、炼丹、坊市、排行榜、邀请领奖。
- 从现有方图改出三套比例：1:1、3:4、9:16；统一品牌角标和 CTA。
- 招募 10 名内部种子玩家做完整漏斗压测。

### 第 1 周｜验证三个内容钩子

同步测试三类素材，每类至少 3 条：

1. 技术反差：`QQ群里直接运行RPG`。
2. 社交反差：`群友每人操作一个回合`。
3. 修仙深度：`五行连招、炼丹、灵兽与宗门`。

只看完播/停留不够，还要比较每条素材带来的注册率、首战率和札记完成率。淘汰“播放高、激活低”的泛流量素材。

### 第 2 周｜百人开荒与群主招募

- 开放 100～300 个名额。
- 每天组织一次固定玩法，收集玩家战报和真实评价。
- 对 20 名候选群主提供三步开服包和专属渠道码。
- B站发布一条完整实机，抖音/小红书用同一事件改编，不直接无脑搬运同一成片。

### 第 3 周｜攻略与玩家内容

- 发布首日路线、角色/流派选择、组队阵法、Boss 机制四类攻略。
- 征集真实战报、群聊名场面与玩家建议；取得授权后再二次发布。
- 上线“本周开发回应”：公开已修复、待修复与不采纳建议及理由。
- 从数据中选出 D7 留存最高的两个来源，加倍内容产出。

### 第 4 周｜裂变与复盘

- 发起“带一位道友完成七项札记”周活动，直接复用现有双阶段邀请奖励。
- 发布群榜/宗门榜、玩家故事和第一个月版本报告。
- 按渠道计算获客成本、激活成本与 D7 留存；只对通过阈值的渠道做小额放大。
- 决定第二月主线：群主渠道、内容达人、攻略 SEO 三者只选表现最好的两项重点投入。

## 8. 内容素材库

### 8.1 五类可长期复用的内容支柱

1. **群聊奇观：** 在 QQ 群里注册、战斗、组队和结算。
2. **策略证明：** 五行反应、道心、Boss 天机、阵法与技能选择。
3. **养成满足：** 境界、本源、装备、灵兽、洞府、药园与炼丹。
4. **社交故事：** 群主开宗、师徒七日、世界 Boss 最后一击、低战力辅助贡献。
5. **开发透明：** 版本更新、Bug 复盘、玩家建议落地、数据平衡。

### 8.2 10 个可立即拍的选题

1. 30 秒把 QQ 群变成修仙服务器。
2. 两个新手能否在今晚打通第一座队伍副本。
3. 不看战力，只靠五行连招能否越级打 Boss。
4. 群友同时炼丹，谁先炸炉。
5. 世界 Boss 只剩 1% 血时，群里发生了什么。
6. 低战力玩家不打伤害，也能靠净化拿贡献吗。
7. 一个文字游戏为什么需要 60 座副本。
8. 玩家第一天最容易浪费的三种资源。
9. 群主建宗门后，死群七天发生了什么。
10. 开发者根据一条群反馈连夜改了什么。

### 8.3 达人合作邀请模板

> 你好，我在做一款“QQ 群聊里直接玩的策略修仙 RPG”。它不是下载类手游：机器人进群后，群友能注册、手动打回合、组队和挑战世界 Boss。我们正在招募首批真实体验创作者，希望你按自己的感受试玩并保留吐槽，不要求统一好评。可提供独立测试群、版本资料和专属渠道码；合作内容与报酬会按平台要求显著标注。如有兴趣，我发你 20 秒实机和测试说明。

达人筛选优先看评论质量和社群感，不以粉丝数为唯一标准。第一轮可找 10～30 位 1 万～10 万粉的修仙、文字游戏、独立游戏或宿舍社交类创作者，小额多样本优于押注单一大号。

## 9. 数据看板与投放决策

### 9.1 每日看板

- 各渠道曝光、入口点击、添加机器人/进群、注册、选角、首战、札记 7/7。
- 当日活跃玩家、活跃群、多人战场次、世界 Boss 参与人数。
- 新手在每个指令步骤的退出率、错误率和平均耗时。
- 机器人错误率、超时率、重复消息率和群投诉。

### 9.2 每周看板

- D1、D3、D7 留存，按来源和创意拆分。
- 每个渠道的注册成本、激活成本、D7 留存玩家成本。
- 邀请系数：每位激活玩家带来的有效新注册数。
- 群扩散系数：每 10 个新增游戏群，一周后仍活跃的群数。
- 内容质量：3 秒留存、完播、收藏/评论、主页访问、入口点击。

### 9.3 放大与止损规则

- 连续两周 D7 ≥ 15%，且激活成本可接受：预算增加 30%～50%。
- 播放高但注册率低：重做 CTA 或人群，不加预算。
- 注册高但首战低：修新手链路，暂停外部扩量。
- 某群出现明显刷屏、投诉或机器人稳定性问题：暂停该群活动，先处理体验。
- 任何 IP、资质或平台审核风险未解决：停止公开投流，只保留封闭测试。

## 10. 预算建议

### 冷启动版｜0～3000 元/月

- 以开发者自制内容、真实玩家共创和群主招募为主。
- 预算用于剪辑模板、字幕、少量素材改版、10～20 位小创作者体验与必要的群活动物料。
- 目标是验证留存和群活，不追求总曝光。

### 验证版｜5000～15000 元/月

- 前提：已通过合规闸门，D7 和活跃群指标达到阈值。
- 50% 用于表现最好的内容平台达人，25% 用于素材生产，15% 用于群主/攻略共创激励，10% 留给复盘后补投。
- 不购买群成员、点赞、评论、预约或注册机刷量。

### 放量版

只有在完成渠道归因、服务器容量测试、客服/群管理 SOP、未成年人和付费合规后再制定。现阶段不建议直接做大额信息流广告。

## 11. 推广所需的产品改造清单

### P0｜推广前完成

- 统一《问道诸天 / 诸天问道》命名。
- 完成授权核验或全量原创化改造。
- 新增渠道码、创意码、注册来源和激活事件。

- 输出隐私政策、用户协议、未成年人说明、概率与奖励规则页面。

- “分享战报”卡片：自动生成玩家名、流派、战斗结果、邀请码与合规入口。

- 群赛季、跨群宗门榜、群主成就等能强化群级传播的玩法。
- 创作者观战/挑战房间，方便直播或录制多人回合。

## 12. 不建议做的事

- 未确认授权和运营资质就公开投流。
- 把知名小说角色当作首要买量素材，却没有书面许可。
- 只发精美 AI 仙侠图，不展示 QQ 群真实玩法。
- 在不相关 QQ 群、贴吧或评论区批量贴群号。
- 用游戏奖励换五星好评、虚假评论或无效转发。
- 同一文案、同一视频无差异铺满所有平台。
- 把设计稿或规划中的功能当成已经上线的卖点。
- 在没有 D1/D7 和渠道归因数据时用总注册量判断推广成功。
