## 实现约束

- 先迁移数据表，再接 Service，再接命令路由和 QQ 展示。
- 消息层不能直接改玩家数据；奖励必须经过带唯一业务键的流水服务。
- 纯文本命令必须始终可用，按钮是交互增强而不是唯一入口。
- 每完成一个阶段，都必须执行文档中的验收清单和并发/重复请求测试。
