# 问道诸天：新手完整玩法指南

## 从零开始

发送 `注册游戏 名称` 创建账号，再用 `选择角色 角色名` 选择第一位主角。选择后发送 `出战 角色编号`，随后打开 `问道札记`；它会按真实完成的操作记录七项入门目标，并在完成后发放灵石奖励。

建议顺序是：选角 → 出战 → 参悟 → 副本战斗 → 药园 → 炼丹 → 商城便利道具 → 群组协作。所有系统入口都可从 `主菜单` 找到。

## 每日成长循环

1. 发送 `参悟` 开始修炼，结束后用 `领取参悟经验` 获得角色经验。
2. 在 `副本菜单` 选择副本；战斗中使用 `战斗行动 普攻/防御/调息/技能-编号`。战斗可以恢复，超过 90 秒会自动防御。
3. 打开 `药园菜单` 购买种子并 `播种 种子名-田号`；成熟后采摘。药材可用于 `炼丹 丹方名-炉号`。
4. 通过副本获得装备和材料，使用装备菜单穿戴、强化；本源菜单可以提升本源等级。
5. 需要节奏便利时打开 `商城`。商城只提供体力、种植与炼丹便利物品，不出售稀有装备、技能或灵兽。

## 回合战斗要点

五行技能会产生状态：水造成潮湿、木造成缠绕、火可触发蒸腾或焚林、金破甲、土护体。每个目标每回合最多触发一次元素反应，因此应根据状态安排下一回合技能。

连续命中同一五行技能可积累道心：3 层可用“道心爆发”或“道心延势”，5 层可“留存道心”强化下一次五行技能。Boss 在关键血量会预告天机；战斗面板会告诉你破局所需五行。成功破局能避免强化，并提高额外材料掉落机会。

## 灵兽、洞府与队伍

在 `灵兽菜单` 中查看图鉴、每日寻访并使用 `灵兽出战 编号`。灵兽来自玩法，不在商城出售。

在 `洞府菜单` 查看四座建筑、升级并每日选择一次稳健收取或冒险共鸣。稳健收益固定，冒险收益会上下浮动。

群聊中使用 `队伍菜单`：队长创建队伍，其他人用队伍码加入；布阵后全员准备。两人以上可开启 `道途`，在六个异步节点中投票。无法在线时会沿用上次投票偏好，不会卡住队伍。

## 装备、本源与技能的提升顺序

副本掉落的装备先在 `装备背包` 中查看，再通过 `穿戴装备 编号` 装备。前期不必急着把所有装备强化到很高：优先保证武器、衣甲和当前出战角色的核心部位，能更稳定地通过副本。更换装备前可查看当前角色属性，确认攻击、防御和气血是否得到提升。

`查看本源` 可以查看角色的流派本源，`本源升级` 会消耗灵石换取长期属性。技能则在 `技能菜单` 中激活、装备和调整；如果战斗面板显示技能冷却或法力不足，先使用普攻、防御或调息度过回合。一个稳妥的前期优先级是：完成札记和日常循环 → 保证主力装备可用 → 提升本源 → 再追求更高阶技能组合。

## 灵石与资源使用原则

灵石主要来自参悟、副本、洞府和札记奖励，用于本源、装备、建筑与商城便利道具。仙玉用于少量功能解锁，使用前请先确认是否有更便宜的玩法来源。药园材料优先留给当前可炼制的丹方；在资源有限时，先播种和收获，再开始炼丹，避免因原料不足中断一炉炼制。

商城的体力药、灵草培育液等物品是节奏便利，不是战力必需品。灵兽、稀有装备、技能卷轴和副本材料均应通过玩法获得。若某项升级提示材料不足，直接回到副本菜单、药园菜单或洞府菜单查看来源，而不是盲目消耗货币。

## 常见问题

**副本战斗中断怎么办？** 发送 `战斗状态` 即可恢复；超过倒计时会自动防御，不会因为未及时回复而丢失会话。

**不知道接下来做什么？** 发送 `问道札记` 查看未完成目标，或发送 `道途建议` 获得当前最合适的一步。

**为什么不能开启三千道途？** 必须在群聊中、至少两名同群成员且全部准备后，由队长发送 `道途开启`。

**哪份说明最权威？** 游戏内以 `主菜单`、`玩法介绍` 与 `更新日志` 为准；版本改动后优先查看更新日志中的新增玩法和命令。

## 常用指令

| 目的 | 指令 |
| --- | --- |
| 查看下一步 | `问道札记`、`道途建议` |
| 角色与修炼 | `当前角色`、`参悟`、`领取参悟经验` |
| 战斗 | `副本菜单`、`战斗状态`、`战斗行动 技能-编号` |
| 生产 | `药园菜单`、`炼丹菜单`、`洞府菜单` |
| 社交 | `灵兽菜单`、`队伍菜单`、`道途` |
| 帮助 | `主菜单`、`玩法介绍`、`更新日志` |

遇到资源不足时，先查看对应菜单的下一步入口；不要急于消费。前期优先完成札记、保持参悟和药园循环，再逐步挑战更高副本与三千道途。
