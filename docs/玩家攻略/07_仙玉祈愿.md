# 仙玉祈愿攻略

- 发送 `仙玉祈愿` 查看奖池；`仙玉祈愿 1次` 消耗 160 仙玉，`仙玉祈愿 10次` 消耗 1500 仙玉。
- 用 `祈愿定向 角色名` 设置目标。未集齐全角色时，第 80 抽主奖励必定给予定向角色碎片；10 个同角色碎片可通过 `合成角色 角色名` 合成角色。
- 每抽主奖励可能为药材、丹药、四星/五星专属碎片或角色碎片；固定奖励还会给当前角色本级所需经验的 1/15（向上取整）和本源材料。
- 满级角色的经验槽自动替换为额外一次本源材料；第 80 抽即使触发保底，固定奖励仍照常发放。

可用 `祈愿记录` 查看最近结果，`祈愿保底选择` 在全角色集齐后预设第 80 抽礼包。
