# 洞府、宗门、世界 Boss、赛季与札记攻略

- `洞府` 查看建筑与产出，`洞府升级 建筑` 消耗灵石升级，`洞府收取 稳健/冒险` 每日收取灵气。
- `宗门创建 名称` 或 `宗门申请 编号` 加入宗门；`宗门委托` 获得贡献，`宗门投票 研究类型` 决定研究方向。师徒功能使用 `拜师 UID`、`收徒 UID`。
- `世界BOSS` 查看世界挑战，参与后在 `世界奖励` 领取对应奖励；贡献越高奖励档位越高。
- `赛季` 查看长期目标，`赛季任务` 获取进度，`赛季奖励` 领取已达成的里程碑。
- `问道札记` 是新手目标清单；逐项完成后用 `札记领取 编号` 领取仙玉，全部完成还有额外仙玉。
