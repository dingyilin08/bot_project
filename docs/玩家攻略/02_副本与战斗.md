# 副本、战斗、装备与技能攻略

- `副本列表 [页数]` 选择副本；`挑战副本 编号` 开始挑战，随后按战斗面板发送 `战斗行动 普攻/防御/调息/御器/专属/技能-编号`。
- 副本会掉落经验、灵石、材料、装备与卷轴。用 `查看怪物` 了解当前波次。
- `装备背包 [页数]` 中选择 `穿戴装备 编号`；同部位会自动替换旧装备。强化使用灵石，出售前需先卸下。
- `技能背包 [页数]` 查看技能；先激活卷轴，再用 `技能装备 槽位-技能编号` 装入当前角色。战斗前可在 `我的战力` 复核装备、技能、本源明细。

技巧：套装件数达到 2/4/6 件会获得全属性加成；强化每级提升该装备 10% 基础属性。
