# v1.22 功能任务总览

更新时间：2026-07-27。状态以当前代码、测试与 [创新玩法功能清单](06_回合制修仙创新玩法功能清单.md) 为准。

## 已完成并可用

- P0 回合战斗：持久化战斗会话、90 秒超时防御、五行基础反应、道心资源、Boss 天机提示。
- 商城与体验道具：体力药、灵草培育液等灵石商品。
- P1 灵兽：每日寻访、图鉴、出战与本源协同。
- P1 队伍阵法：同群组队、准备、前后列及锋矢/玄武/流云阵法。
- P1 洞府：四类建筑、升级、稳健或冒险的每日收取。
- P1 三千道途首发：2~4 人、6 节点、异步投票、超时偏好、因果印记与幂等奖励。
- 菜单与指令：参数输入按钮；队伍、灵兽、洞府独立菜单；更新日志 v1.22。
- P0 完善：每目标每回合一次元素反应、可配置 Boss 天机与破局掉落权重。
- P2 问道札记：七步真实行为引导、可幂等领取奖励与个人下一步建议。

## 实施顺序

先完成 P0 战斗约束，再完成 P1 多人统一结算和丹道闭环；这三项稳定后才接入宗门与世界 Boss。赛季和新手札记最后上线，以免引导玩家进入尚未稳定的社交玩法。

每个 TXT 都包含玩法循环、玩家指令、数据、验收和边界；开发时应先更新对应文档状态，再实现迁移、命令、测试和更新日志。
