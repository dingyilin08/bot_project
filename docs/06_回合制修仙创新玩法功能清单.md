# 问道诸天：回合制修仙创新玩法功能清单

> 目标：把当前“数值养成 + 自动副本”升级为适合 QQ 指令交互的“可决策回合战斗 + 长线修仙关系网”。本清单不复制竞品数值，而是提取其可验证的设计方向：灵兽的反制、增益、复活等战术功能可提升回合选择密度；可参考[《问道》宠物技能资料](https://wd.leiting.com/home/game/game_data.php?level=2&level_id=41&show_type=1)。职业变身、灵兽协同与状态连锁能形成清晰战斗节奏，可参考[《梦幻新诛仙》技能设计](https://mhxzx.games.laohu.com/news/gamenews/20260625/262880.shtml)。洞府将修炼、种植、炼丹、炼器与灵兽统一为一个家园中枢的做法，见[《一念逍遥》洞府介绍](https://xian.leiting.com/news/3.html)。炼丹的配方成长、药引、品质结果及耐药约束，见[《诛仙手游》炼丹资料](https://zx.wanmei.com/hd/1904/version/list1.html)。

## 0. 当前基础与设计边界

现有项目已具备角色/本源/技能/装备/副本/药园炼丹/商城，以及 `Game_domain` 中的战斗会话、奖励幂等和事件去重能力。新玩法应遵循：

- 不出售装备、技能卷轴和稀有材料；商城只卖节奏便利。
- 所有多人或跨回合玩法必须有 `session_id`、超时自动动作、幂等 `action_id`、可恢复快照。
- QQ 按钮只是快捷入口；所有操作必须有文本指令降级路径。
- 先让一场战斗变得“有选择”，再扩大社交、赛季和排行榜。

## 1. P0：可玩的回合战斗（先完成）

### P0 实施状态（2026-07-26）

- [x] 单人副本已切换为 90 秒可恢复回合会话；超时默认防御，重复 `action_id` 幂等。
- [x] 已提供 `战斗状态`、`战斗行动 普攻/防御/调息/御器/道心爆发/道心延势/留存道心/技能-编号` 及 QQ 点击面板。
- [x] 已实现水火蒸腾、木火焚林、金行破甲、土行护体，以及 Boss 75%/40% 天机破局窗口。
- [x] 同系技能可积累 1~5 层道心；3 层可爆发或延势，5 层可留存以强化下一次五行技能。
- [ ] 每回合最多一次反应、Boss 机制配置表与破局掉落加权留待后续 P0 迭代。
- 部署前需执行已跟踪的 `数据库源文件/battle_session.sql`，创建战斗会话、行动与事件表。

### 1.1 战斗行动盘

- [ ] **功能**：每回合给玩家提供“普攻、三个已装备技能、御器、防御、调息”六类行动；明确显示法力、冷却、护盾、控制、持续伤害和行动顺序。
- [ ] **创新点**：加入“道心”资源。连续使用同系/同类技能会积累道心；在 3/5 层时选择爆发、延长状态或保留到下一回合，形成短回合资源博弈。
- [ ] **接入**：基于 `battle_session` 快照保存 `mana`、`cooldowns`、`buffs`、`dao_heart`、`round_no`；复用 `Tool/combat_system.py` 的伤害与 Buff 结算。
- [x] **指令**：`挑战怪物 编号`、`战斗行动 普攻`、`战斗行动 技能-编号`、`战斗行动 御器`、`战斗状态`。
- [ ] **验收**：同一回合重复 `action_id` 不重复结算；超时 90 秒自动防御；重启后可继续战斗；日志能解释伤害来源和状态变化。

### 1.2 五行相生与状态反应

- [x] **首发规则**：技能支持显式五行标签，并对旧技能名做兼容推断；水→潮湿、火击潮湿→蒸腾、木→缠绕、火击缠绕→焚林、金→破甲、土→护体。

- [ ] **功能**：技能补充金、木、水、火、土标签，以及灼烧、潮湿、缠绕、破甲、迟滞五种基础状态。
- [ ] **规则**：水→潮湿、火击潮湿触发“蒸腾”并清除潮湿；木→缠绕、火击缠绕触发“焚林”扩散灼烧；金击破甲目标获得额外破防；土为护盾/嘲讽/净化定位。
- [ ] **约束**：每个目标每回合最多触发一次反应；PVE 先做，PVP 只开放经过平衡的反应系数。
- [ ] **验收**：战斗日志显示“施加—触发—清除”三段因果；相同输入与随机种子可复盘同一结果。

### 1.3 Boss 天机与破局窗口

- [x] **首发机制**：Boss 于 75%/40% 血量触发可读预兆；分别以金行/水行技能破局，失败则获得短回合防御/攻击强化。

- [ ] **功能**：Boss 在 75%/40% 血量或特定回合进入天机阶段，提前一回合公布“蓄力、召唤、护体、易伤”等预兆。
- [ ] **创新点**：玩家不只拼战力，可用五行反应、打断、护盾、净化或集火完成“破局”；成功给额外掉落权重，失败也保留最低通关奖励。
- [ ] **数据**：`data_boss_mechanic`（触发条件、预兆、应对标签、成功/失败效果）、`battle_event`（可追溯事件）。
- [ ] **验收**：每个新 Boss 至少有两种可行应对方式；无打断技能的队伍仍可通过防御/净化过关。

## 2. P1：角色之外的战术搭档

### P1 实施状态（v1.21）

- [x] 灵兽园已支持副本后每日寻访、1 只出战与 3 只收藏、资质/性格/血脉展示，以及可恢复的战斗灵契 Buff。
- [x] 群队伍已支持同群创建、加入、准备、离开和三套公开阵法（锋矢、玄武、流云）及前后列配置。
- [x] 洞府已支持聚灵阵、炼器台、灵兽园、藏经阁四座建筑的 1~10 级升级，以及每日稳健/冒险共鸣收取。
- [x] 三千道途首发支持 2~4 人群组异步秘境、6 个固定节点、全员投票/超时偏好托管、节点幂等奖励与因果印记记录；多人战斗统一结算、丹道药性和 P2 宗门/赛季仍按下述依赖顺序继续开发。

### 2.1 灵兽与血脉

- [ ] **功能**：每位玩家可携带 1 只出战灵兽、3 只灵兽园收藏；灵兽有资质、性格、血脉和 2 主动 + 1 被动技能。
- [ ] **定位**：输出（追击）、护法（分担/护盾）、灵医（治疗/净化）、扰敌（减速/封印）。避免灵兽只是第二套角色数值。
- [ ] **创新点**：灵兽的被动会读取主角的本源标签，例如异火本源触发灼烧协同、轮回本源获得一次濒死回魂、掌天本源复制一次低阶 Buff。
- [ ] **来源**：秘境捕获、宗门孵化、限时世界事件；不放入灵石商城。
- [ ] **数据**：`data_spirit_beast`、`data_beast_skill`、`user_spirit_beast`、`user_beast_bond`。
- [ ] **验收**：同一灵兽在不同本源角色下有可读的不同策略；灵兽离场不导致战斗软锁。

### 2.2 阵法与双前排

- [ ] **功能**：战前在“前列/后列/灵兽位”配置 2 人或 4 人队伍；首发开放 3 套阵法：锋矢（爆发）、玄武（生存）、流云（先手）。
- [ ] **创新点**：阵眼由队伍中某个本源承担；阵眼被控制时阵法降低一档，迫使玩家兼顾保护与输出。
- [ ] **指令**：`队伍创建`、`队伍加入 编号`、`布阵 阵法-位置`、`灵兽出战 编号`。
- [ ] **验收**：阵法提供明确百分比而非隐藏修正；匹配战力相近时三种阵法均存在可用场景。

## 3. P1：三千道途（异步 Roguelite 秘境）

- [ ] **功能**：3~4 人可创建一局 20 分钟内完成的秘境；路线由 6~8 个节点构成：战斗、奇遇、药圃、遗宝、疗养、Boss。
- [ ] **创新点**：每位成员每节点投票一次，队伍用“因果印记”记录取舍。印记会改变后续节点，例如救下丹师可降低炼丹消耗，夺取遗宝会提高 Boss 护甲但增加掉落。
- [ ] **异步体验**：队长选路，成员在倒计时内提交行动；缺席者按上次偏好自动投票，避免 QQ 群聊等待卡死。
- [ ] **奖励**：保底灵石/药材，按破局次数、探索率、因果印记结算“道途残卷”；残卷只用于解锁流派外观、词条池与低幅便利，不做直接碾压属性。
- [ ] **数据**：扩展 `battle_session`，或新建 `expedition_session`、`expedition_member`、`expedition_node_log`、`user_causal_mark`。
- [ ] **验收**：断线成员重连可看到完整路线和历史选择；重复事件不会重复发奖；一局不超过 15 条机器人回复。

## 4. P1：洞府重构为“修仙生产中枢”

### 4.1 洞府建筑

- [ ] **功能**：以现有药田/丹炉为基础增加聚灵阵、炼器台、灵兽园、藏经阁四个建筑，建筑 1~10 级。
- [ ] **产出关系**：聚灵阵提升参悟效率；灵兽园提供灵兽培养/派遣；炼器台消耗副本材料重铸装备词条；藏经阁解锁流派教学和每日研究。
- [ ] **创新点**：洞府不强制定时收菜。离线产出有容量上限，玩家可选择“稳健产量”或“冒险共鸣”；后者可能提高品质，也可能产生需要处理的小事件。
- [ ] **验收**：任意建筑升级都能在当前玩法中找到至少一个即时收益和一个长期收益；不引入新的付费货币。

### 4.2 丹道研习与药性

- [ ] **功能**：丹方拥有熟练度、品质结果（寻常/小成/大成/圆满）、药引槽与耐药值；沿用现有 `pill_usage`，拆分为每类丹药的药性计数。
- [ ] **创新点**：玩家可在炼制前选择“保守、均衡、冒险”火候。冒险不单纯提高成功率，而是改变品质权重与炸炉代价；药引来自副本/药园/宗门协作。
- [ ] **控制**：永久属性丹严格设置耐药上限；战斗消耗丹进入副本时限定携带数，保证回合策略优先于药品堆叠。
- [ ] **验收**：玩家无需购买加速道具也能稳定完成日常炼制；每个品质结果均有明确数值与来源说明。

## 5. P2：宗门、师承与世界协作

### 5.1 宗门议事与师承契约

- [ ] **功能**：宗门支持申请/审批、职位、建设、每日委托和贡献商店；高境界玩家可收 1~3 名徒弟，徒弟完成成长目标时双方获得贡献和师缘。
- [ ] **创新点**：每周宗门投票确定研究方向（炼丹、阵法、御兽、秘境），全员共享一项小型赛季被动；避免纯会长单向建设。
- [ ] **保护**：师徒只共享任务进度与奖励，不转移装备、灵石、账号控制权；连续不活跃自动解除契约。
- [ ] **数据**：`sect`、`sect_member`、`sect_research`、`master_apprentice`、`sect_vote`。
- [ ] **验收**：小宗门也能完成基础贡献循环；宗门研究效果有 PVE 上限，不影响竞技公平。

### 5.2 诸天共伐（服务器世界 Boss）

- [ ] **功能**：每周 2 次，全服或按宗门协作挑战多阶段世界 Boss；每位玩家最多 3 次挑战，取最高有效伤害。
- [ ] **创新点**：Boss 以“世界法则”轮换（火劫、水劫、轮回劫等），匹配五行和本源流派；所有人提交的破局次数共同推进服务器奖励阶梯。
- [ ] **奖励**：参与保底、个人伤害档、宗门协作档三层；奖励以材料、外观、称号、炼器资源为主。
- [ ] **验收**：低战玩家通过辅助/破局也可获得完整参与奖励；排行榜和发奖均以幂等结算单为准。

## 6. P2：赛季化长期目标

- [ ] **功能**：8 周为一季，每季一个“诸天异象”主题与地图规则；赛季等级通过副本、秘境、宗门任务推进。
- [ ] **创新点**：赛季只重置“异象研究、赛季地图、临时法则”，不重置角色、装备、本源、药园和洞府，保护养成投入。
- [ ] **赛季法则示例**：本季火系反应伤害提高、轮回印记有额外分支、特定世界副本出现镜像 Boss。
- [ ] **验收**：新玩家可在 7 天内获得赛季基础奖励；老玩家优势来自策略广度而非不可追赶的永久数值。

## 7. P2：新手引导与体验保障

- [ ] **功能**：建立“问道札记”七日目标，依次引导角色、参悟、首场手动战斗、药园、炼丹、商城、秘境组队。
- [ ] **创新点**：目标奖励优先发“选择券”而非固定材料，让玩家首次确定火/水/木等战斗倾向；引导结束后生成一份个人“道途建议”。
- [ ] **体验规则**：所有关键失败点给出下一步按钮，如材料不足链接至副本/药园，体力不足链接至商城与免费恢复时间说明。
- [ ] **验收**：新账号在 20 分钟内完成第一次主动技能、第一次药田收获和第一次副本结算；没有任何一步要求付费。

## 9. 不做清单与衡量指标

- [ ] 不做装备抽卡、灵石直购稀有材料、无限叠加的永久属性丹。
- [ ] 不把多人活动设计成必须实时在线；默认支持超时托管和次日结算。
- [ ] 不在 P0 前上线 PVP 天梯或跨服战，先完成可解释、可恢复的 PVE 回合体验。

首月观察：首场手动战斗完成率、回合平均决策时长、药园/炼丹回流率、商城便利道具购买率、秘境组队完成率、幂等结算错误率。满足“决策可读、失败可补救、奖励可追溯”后，再扩大赛季与社交内容。
