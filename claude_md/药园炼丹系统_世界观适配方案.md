# 药园与炼丹系统 — 六大世界观适配开发方案

> 基于《斗破苍穹》《仙逆》《凡人修仙传》《完美世界》《遮天》《沧元图》六部小说世界观，
> 参考 wanggu 项目药园/炼丹模块设计，适配当前 Bot_project 项目架构。

---

## 一、世界观药草名录（每世界 20 种）

### 设计原则

- 每个世界 20 种药草，按品阶分为 4 档（凡品/良品/精品/仙品）
- 药草命名贴合原著世界观、修炼体系、标志性意象
- 品阶越高产出越少、种植成本越高、用于合成高阶丹药
- 跨世界药草互不通用，强化世界归属感

## 二、六大世界丹药名录

### 设计原则

- 丹药分为 **通用丹药**（所有世界共用配方）和 **世界专属丹药**（特定世界药材炼制）
- 通用丹药提供基础属性加成，世界专属丹药提供更强的特色加成
- 每个世界额外设计 3-4 种专属丹药，强化世界特色
- 配方要求：通用丹药 = 任意世界凡品/良品药材组合；专属丹药 = 本世界精品/仙品药材


## 七、核心流程详解

### 7.1 种植 → 采摘

```
购买种子(灵石) → 种子进入 user_seed_bag
    ↓
播种(种子名-田号) → 扣减 user_seed_bag, 写入 yt_N JSON {is_zz:1, zz_id, time:now}
    ↓
等待 7200 秒（2小时）  // 或施肥跳过
    ↓
采摘(田号) → 判断 now - time >= 7200
    ├─ 未成熟 → 返回剩余时间 "还需 XX 分 XX 秒"
    └─ 已成熟 → random(min, max) 根据 tier 产出药材
                 写入 user_item(uid, herb_item_id, num)
                 重置 yt_N = {is_zz:0, zz_id:0, time:0}
```

产出数量区间：

| tier | 最少 | 最多 |
|------|------|------|
| 1    | 8    | 12   |
| 2    | 6    | 10   |
| 3    | 4    | 8    |
| 4    | 2    | 5    |

### 7.2 炼丹 → 服丹

```
炼丹(丹药名-炉号)
    → 查 data_recipe 获取 ingredients, need_num, cost
    → 扣灵石 cost
    → 逐一检查 user_item 中各原料 >= need_num
    → 逐一扣减原料
    → 写入 dl_N = {is_lz:1, df_id:recipe_id, time:now}
    ↓
等待 3600 秒（1小时）  // 或加速卡跳过
    ↓
收丹(炉号) → 判断 now - time >= 3600
    ├─ 未完成 → 返回剩余时间
    └─ 已完成 → roll = random(1,100)
        ├─ roll > 10 (90%) → 成功，add user_item(uid, pill_id, 1)
        └─ roll <= 10 (10%) → 炸炉，无产出
        → 重置 dl_N = {is_lz:0, df_id:0, time:0}
```

### 7.3 服丹效果应用

```
服丹(丹药名-数量)
    → 查 data_pill 获取 effect_type, effect_value, is_percent, max_use
    → 查 user_role.pill_usage 获取已用次数
    → 判断 已用 + 数量 <= max_use
    → 循环 N 次:
        ├─ effect_type = "gongji"  → UPDATE user_role SET gongji = gongji + value
        ├─ effect_type = "fangyu"  → UPDATE user_role SET fangyu = fangyu + value
        ├─ effect_type = "qixue"   → UPDATE user_role SET qixue = qixue + value
        ├─ effect_type = "exp"     → 按百分比加经验
        ├─ effect_type = "sell"    → 直接加灵石
        └─ effect_type = "baoji/shanbi/mingzhong/pofang/xixue"
              → UPDATE user_role SET {attr} = {attr} + value (百分比)
    → 更新 pill_usage 计数
    → 扣减 user_item
    → 触发战力重算
```

**多属性丹药处理**：世界专属丹药可能同时加多个属性（如 +80气血+8攻击），
`effect_type` 和 `effect_value` 用逗号分隔存储，Python 侧 split(',') 逐一应用。

## 十二、开发注意事项

1. **JSON 字段读写** — MySQL 5.7 支持 JSON 类型但函数有限，建议 Python 侧用 `json.loads`/`json.dumps` 处理
2. **并发安全** — 采摘和收丹操作使用乐观锁：先 UPDATE 改状态，检查 `rowcount == 1` 再发放奖励
3. **参数解析** — 后缀参数用 `-` 分隔（如 `购买种子 冰灵焰草种子-5`），函数内 `split('-')` 解析
4. **分页** — 种子商店和丹方列表每页 8 条，参考现有模块分页方式
5. **药材存储** — 药材和丹药作为普通物品存入 `user_item` 表，需要在 `data_item` 表中为每种药材/丹药新增记录（或独立使用 `data_herb`/`data_pill` 表，`user_item` 中通过 `item_type` 字段区分）
6. **战力联动** — 服丹直接修改 `user_role` 属性列，需调用 `Tool.tool_power.update_role_power()` 刷新战力
7. **初始化时机** — 玩家首次输入「药园」或「查看丹炉」时懒初始化，避免注册时创建空行
8. **世界归属** — 种子商店默认展示出战角色所属世界，但玩家可以购买任意世界的种子并种植
9. **跨世界炼丹** — 通用丹药可用任意世界的凡品/良品药材，专属丹药严格要求本世界药材
